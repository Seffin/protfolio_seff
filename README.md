A high-performance, autonomous personal developer portfolio and telemetry dashboard built with **Next.js 16 (App Router)**, **React 19**, and **Tailwind CSS v4**. 

It dynamically aggregates live GitHub repository metadata, real-time commit activity, Vercel deployments, framework upgrade advisories, Dependabot security metrics, and visitor traffic to present an interactive showcase of projects and professional experience.

---

## 🌟 Key Features

- **Automated Repository Showcase**: Fetches all public repositories directly from GitHub, grouping them into Hero projects, Hosted apps, and Open-source tools.
- **Deep Framework Detection & Upgrade Advisor**: Inspects remote `package.json` dependencies across 6 frameworks (Next.js, Astro, Nuxt, SvelteKit, Remix, Gatsby), compares installed versions against upstream GitHub releases, and displays live upgrade recommendation badges (`<MdUpgrade />`).
- **Live Traffic & Security Telemetry**: Monitors 14-day unique visitors and daily active traffic, along with color-coded Dependabot vulnerability advisories.
- **AI Agent & Copilot Collaboration Metrics**: Queries GitHub GraphQL to display merged pull requests generated by GitHub Copilot (`copilot-swe-agent[bot]`).
- **Interactive User Explorer (`/search`)**: Allows visitors, recruiters, or other developers to enter *any* GitHub username to preview their own profile and repositories dynamically rendered in this portfolio layout.
- **Modern Contact Dashboard (`/contact`)**: Split-screen communication view with instant links (Phone, Email, LinkedIn, WhatsApp, Google Maps location, Instagram, Facebook) and an interactive client-side message form with animated submission states.
- **Integrated Resume & One-Click PDF Download**: Features a visual career timeline and full-stack credentials on the homepage alongside a direct download button for the compiled ATS-friendly PDF resume (`Seffin0.1.pdf`).
- **Aggressive Tiered Caching**: Next.js `unstable_cache` with custom revalidation TTLs (5m, 1h, 12h, 24h) and client-side route caching (`staleTimes: { dynamic: 300, static: 300 }`) ensures near-zero latency and prevents hitting GitHub API rate limits.
- **Zero-Token Fallback**: Gracefully degrades to public unauthenticated GitHub REST APIs if tokens are not configured, avoiding runtime crashes.

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router + Turbopack)

## 🚀 Quick Start

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/Seffin/portfolio.git
cd portfolio
npm install
```

### 2. Configure Environment Variables
Copy the example environment template:
```bash
cp .env.example .env.local
```

Edit `.env.local`:
```env
# Optional but recommended (elevates API rate limits from 60 to 5,000 req/hr):
GH_TOKEN=ghp_yourGitHubPersonalAccessToken

# Optional (queries live Vercel deployments and preview URLs):
VC_TOKEN=yourVercelToken
```

### 3. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view your portfolio locally.

### 4. Build for Production
```bash
npm run build
npm run start
```
